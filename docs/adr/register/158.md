Precedence has two rules, both true: the specific domain wins for a value, and a higher domain locks one with `override: immutable`; the contract, the layering document and the shared `policy_domain` definition now agree. The packet proposed adding `gating`; the terminology gate records it was merged into the Validation Policy, so the dead output branch is removed instead. Two must-reject cases.
