**A volume's reclaim policy has the Kubernetes name and values** (#680). Volume `retain_on_release`, a boolean, becomes `reclaim_policy`: Retain \| Delete, the Kubernetes PV `persistentVolumeReclaimPolicy` copied verbatim and marked `x-standard`. That is the same name and spelling as the StorageClass `reclaim_policy` default it overrides, so the class and the volume no longer say one thing two ways. Recycle, deprecated upstream, is left out. Volume 0.16.0 is a breaking rename, MINOR under the pre-1.0 floor. The rule it applies: mirror the adopted standard's names in snake_case where the meaning is identical, and keep a verbatim value set in its standard's spelling (row 111).
