**A field that names another entity is a reference, not a bare string.** Machine.VM 2.2.0: `placement.location_ref` is a Reference, and `placement.affinity[].target` is a URF filter, because a selector may match many resources. Container 1.2.0: `process.env[].value_from.credential_ref` and `process.mounts[].source_ref` are References. TestEvidence 0.4.0: `result.report_ref` is a location, not an entity, so it declares `format: uri-reference`. The OSPatch engine classes keep `definition_ref` as a string, because it is the engine-native name a Provider class exists to carry; their descriptions now say so. Gate G3 now checks `*_ref` properties at any depth and accepts a declared `uri` or `uri-reference`; it had checked the top level only, and its array check sat in a loop that never ran. Closes #642.
