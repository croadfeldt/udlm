**Six text rulings, in plain English** (lockdown WP6b). Identity is not address: UDLM says what a thing is, never how a provider reaches it; endpoints are outputs (#328). A pinned URF resolves to that version for ever; an unpinned one to the current version each time it is read (URF-014, #382). A dot is a type-name separator, a field-path separator, or a literal character in a value (#491). The record-content test carries its reason, retention: design rule 43 (#428). `supports` carries no presentation (#401). There is no `activation_condition`: a layer applies by `covers` and `applies_on`; a condition on request data is policy (LAY-003, #392). The spec names an implementation only as an example: 21 lines rewritten (#503). #460 was already done; #416 moves to 1.x. Maintainer rulings 2026-11-03.
