**The map from intent to realized is provenance, checked as a diff; the integrity chain stays per state stream.** A requested record references its intent (`intent_ref`) and a realized record references its requested (`requested_ref`). Every leaf that differs between a record and the record it references carries a `provenance` entry naming who changed it and the value it replaced. Every realized output is attributed. An unattributed difference fails CI (`TRN-001`). A reference to a sealed record carries that record's head, so the transition is bound to bytes (`intent_ref_head`, `requested_ref_head`, `TRN-002`). `integrity.previous` links versions within one state's stream only; the first record of a state is a chain root. The cross-state map is the references, never the chain. Spec home `audit-provenance-observability.md` §2.5; schema `state-record.schema.json`; gate `tests/check_transition_provenance.py`. Maintainer ruling 2026-09-27.
