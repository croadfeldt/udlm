**One disk shape, shared by machines and node pools.** `common-elements.schema.json` gains `disk` (name, size, optional storage tier and role), lifted from Machine `disks` (row 112); Machine 2.4.1 now lists it by reference. KubernetesNodePool 1.2.0 gains `node_disks`, the disks every node gets, as a list of the same shape. Cloud pools expose one size per node (GKE diskSizeGb, EKS volume size, AKS osDiskSizeGB), which is a one-entry list of role `boot`; Cluster API templates carry a disk list. The control plane can now record a cluster order that sizes its node disks instead of refusing it. Reuse before coining (T7). Closes #650.
