**The spec is the source of truth; everything else is built from it.** The normative text under `docs/spec/` is the model. Schemas, gates, generated artifacts, worked examples, read models and tools, consumer manifests and explanatory documents are derived surfaces. A derived surface is brought into line in the same change that moves the spec. It never states a rule the spec does not (`DOC-002`, `CONTRIBUTING.md`; `registry-governance.md` §3.1). Maintainer ruling 2026-09-27.
