**Every field the spec mentions has a schema, or the mention goes.** Three rulings: `ownership_model` stays optional, and a profile that enforces tenancy may require it (OWN-009). A class declares its outputs or says it has none and why (`outputs_exempt`); an output a record carries that the class did not declare is kept but promised to nobody, unless the class is `outputs_closed`. A cross-tenant grant ends by stated criteria, never by omission: `expires_at` is required, and `ends_when` lists scored criteria with a threshold (CTX-009). New homes: `rebuilt_from` and `provider_entity_id_history` on the state record; `reduction` on the served view; one `handle` grammar in common-elements that every record schema uses. Fill strategy is derived from `supports`, not stored. `reference_data` stays a layer type (ruling 2026-08-11). Closes #351 #352 #353 #445 #412 #415 #469 #406 #559 #189.
