**Settings precedence resolution is reuse, not a new mechanism.** Resolution is the derived projection of ADR-015 §2a: select, order, compose, and yield the effective value with its provenance. It is computed, never stored. Per-value provenance is the layering rule (LAY-005, LAY-008). Generated projections carry render provenance (ADR-045 §7). This row adds one thing, the same-tier tie-break. A tier declares an explicit `precedence_order`. An undeclared same-tier conflict on one setting is a typed refusal that names both sources. | Ruled — row-only; applied by construction: the content is "reuse [ADR-015](ADR-015-settings-and-config-bundles.md) §2a", which is kept prose
