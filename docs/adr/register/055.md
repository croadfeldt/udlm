**Worked examples live in the spec.** Each spec carries its examples at `spec.examples`, the JSON Schema / OpenAPI 3.1 `examples` keyword, co-located with the schema and adopted by reference (T5). Every in-spec example must validate against its own spec schema; the check is Spectral's `oas3-valid-schema-example`, run UDLM-side, and it is hard (`EXG-001`). Every spec carries one unless it is burn-down-baselined (`EXG-002`). The example is a non-normative annotation excluded from the identity digest, so refreshing it never forces a version bump (ADR-051). External-only examples collapse back into the spec.
