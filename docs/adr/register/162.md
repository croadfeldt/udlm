**A decision record's "realized by" pointer follows the file it names.** Six decision records said they were realized by `registry/realized-entity.schema.json`, a file renamed to `entity-view.schema.json` when the per-state records landed (row 071); the fields they name now live in `state-record.schema.json`. A decision is a record and is not edited; the pointer is bookkeeping about where the decision is built, not part of the decision. Ruling 2026-11-04: when a named surface moves, the pointer is corrected in place, and the register row that moved the surface is the trail. Six headers now name `state-record.schema.json`, or `entity-view.schema.json` where the decision is about the folded view (ADR-030). A path inside a record's body stays as written: the body is the decision as recorded, and the gate that forbids editing an accepted record (ADR-REAL-004) holds there. The realization gate (ADR-REAL-002) already requires every surface a header names to exist. Closes #725.
