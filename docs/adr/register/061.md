The classes directory mirrors the class hierarchy — `registry/classes/<family>/<segments-as-path>.yaml` (index-file template: a base — childless included — is a directory holding `_base.yaml`; types/providers are leaf files until they gain children; no tier/version dirs). The path RESTATES record facts, so it is admitted only as a **verified projection**: `CLS-PATH-001` gates path == family + segment chain and parent == directory ancestry; records stay the sole source, paths are navigation | Proposed
