**One run state for every Machine; a mapped field may change shape when the class states the provider's translation.** Machine.VM, Machine.LPAR and Machine.BareMetalHost each said `run_state` differently. Machine 2.3.0 declares `run_state.desired_state` (`running`, `stopped`, `suspended`) and `outputs.observed_run_state` once; the types inherit them; an LPAR never takes `suspended`. BareMetalHost 0.16.0 drops `online` and `power_state`; its Metal3 and Redfish adoption entries state the translation: `running` is `online: true`, and Redfish `PowerState` On, Off and PoweringOn land as `running`, `stopped`, `transitioning`. The rule: UDLM adopts by reference (T5) and never emits a native spec (T9), so a mapped field is UDLM's to shape when the class says how the provider translates it. Only a field copied verbatim and marked `x-standard` is frozen to its standard. Second ruling: KubernetesNamespace 1.2.0 drops its `tenant_uuid` element; the envelope's `tenant_uuid` is the owner, and another tenant using the namespace holds a stake. Maintainer rulings 2026-10-23 (#664, compute group).
