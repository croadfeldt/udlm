**A criterion may match a pattern: `=match=` takes an I-Regexp (RFC 9485).** One more comparator in the URF query axis, beside the glob and literal ones it does not replace. The comparator declares the value's language — a glob after `==`, a pattern after `=match=` — so no separate dialect field is needed, and a peer whose spec version predates `=match=` refuses it rather than misreading it (URF-001). The pattern is single-quoted, matched against the whole value, literal (no `{self}`), and percent-encoded like any value in the canonical form. Anchors are refused: I-Regexp reads `^`/`$` as literals, so they would silently never match (URF-012). URF-008 now exempts `=match=`. Maintainer ruling 2026-10-14.
