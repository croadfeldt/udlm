**A vulnerability record says whether it is being exploited** (Vulnerability 0.4.0, #TBD). Severity says how bad a vulnerability could be and not whether anyone is using it, and `Vulnerability` carried only severity and CVSS. Two optional elements are added with the values of two SSVC decision points: `exploitation` (none, poc, active) and `automatable`. Both are facts about the vulnerability that public feeds state, and an entry in a known-exploited catalog is evidence for `active`. Absent means no source has said, and is never read as `none`. The other two inputs of SSVC's decision for an organization that applies patches are facts about the estate and stay there: how far a workload is reachable (`exposure`, row 166) and the impact on the organization. An exploit-prediction score is not carried. Proposed 2026-11-18, not yet ruled.
