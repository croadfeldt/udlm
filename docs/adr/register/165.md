**A machine says how its operating system is delivered.** Maintainer ruling 2026-11-08, after `update_all` was rewritten for image-mode hosts. `Machine.guest_os` (inline form) gains two optional fields: `delivery`, `package` or `image`, and `image_ref`, the booted image's transport, reference and digest. The update tool reads the first to choose a package manager or a new image; the second is observed, so a rebuild or rollback is checked against what runs. Machine takes a MINOR to 2.7.0 and Machine.VM, which redeclares the element, to 2.5.0. The estate's discovery probe emits both from `/run/ostree-booted` and `bootc status`.
