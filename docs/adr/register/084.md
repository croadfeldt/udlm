**The Hardware folder dissolves** (ADR-082 applied). `StorageDevice`, `NetworkInterface`, `Processor`, `GPU` and `BMC` are Bases by the Base test, filed under `hardware` (a drive also under `storage`, an interface also under `network`); `device_class` has one home in `common-elements.schema.json` and each Base declares the subset it can be. `Hardware.GraphicsProcessor` is the `GPU` Base, not a Type of `Processor`: nothing ports between a CPU and a GPU. `Hardware.BiosProfile` is retired: its portable part is Machine's `firmware` element, a vendor attribute set is Provider Class data. Same uuids; map in `registry/renames.yaml`. Maintainer ruling 2026-09-29.
