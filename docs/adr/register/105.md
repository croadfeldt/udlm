**A record's `type_ref` has one correct form.** It names where the pinned class is served: the served spec's `$id` (`…/udlm/0.1/<Class>/<version>`), the file a consumer fetches and validates against. A Provider class has no served spec, so a record pinning one gives the class `$id` (`…/udlm/0.1/class/<Class>/<version>`). The pinned class is the record's `resource_type` or a class beneath it, and its version is `type_version`. Twelve worked records that used the class form for a served class are re-issued: new ids superseding the old, resealed where sealed. Gate `tests/check_type_ref.py` enforces the rule; run against main it finds those twelve. Maintainer ruling 2026-10-22. Closes #643.
