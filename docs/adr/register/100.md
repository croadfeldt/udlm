**A standard named in prose is an adoption claim.** KubernetesNodePool 1.1.3 adopts the Kubernetes core/v1 Node (`labels`, `taints`, a taint verbatim) and the Cluster API MachineDeployment (`node_count` is its `replicas`). Gate G5 now treats the name of any standard some class adopts as a claim, not only a fixed token list, so a Base test that names a standard with an empty `adopts` fails. A description that names standards only as examples says so with `adopts-exempt:`; CredentialRef 0.8.2 does, because a reference adopts none of the secret stores it names. LogShipper already adopts OpenTelemetry (row 096). Closes #646.
