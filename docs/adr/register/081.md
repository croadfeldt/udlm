**Dispatch is zero trust.** A provider gets nothing by default (`DSP-001`). It gets the elements of the class it binds (`DSP-002`) and whatever a policy with the authority to grant it grants (`DSP-003`). A class or provider may mark an element control-plane-only; that only narrows. The control plane adds control-plane-only data as it needs. A provider may declare needs beyond its class (`requests_data`, `PRV-013`); policy answers. Who may write a granting policy is authorization, not dispatch. The requested record's `dispatch` block is the receipt (`DSP-004`). Home `data-roles.md` §3; `data_role` moves to `common-elements.schema.json`; elements gain `role` (`CLS-009`).
