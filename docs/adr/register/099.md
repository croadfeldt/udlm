**`allocation_state` is not `lifecycle_state`.** Machine.BareMetalHost and NetworkSwitch had an element `lifecycle_state` (`available`, `allocated`, `retired`) that says whether a raw resource has been adopted. The entity view's `lifecycle_state` is the four-state position. One name had two meanings, so the element is now `allocation_state`: BareMetalHost 0.15.0 and NetworkSwitch 0.9.0, a MINOR bump under the pre-1.0 floor. common-elements §6, SPEC-DESIGN-REQUIREMENTS §28 and four-states §2.4 follow. DEP-007 now says the tombstone is `lifecycle_state: Decommissioned`, which its note used to have to explain. Estate records that carry the element rename downstream. Part of #640; the curation `state` on decision and composition records is a separate ruling.
