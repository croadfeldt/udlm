**The conformance suite exists: record level, suite 1.0.0** (WP7, #417, #442; lockdown ruling 2). `tests/conformance.py` takes a directory of an implementation's records and applies every rule a record can be judged by. They are the state-record schema on stream heads (binding CLS-010, DEP-015, RHY-007, WIR-001/002/003/007), integrity chains (INT-001/002), transition provenance (TRN-001..003), fulfillment conditions (FUL-001..003), dispatch receipts (DSP-002..004) and payload depth at the pinned class version. An unserved version is reported, not failed. The schema and payload checks are named for what they check and mint no rule IDs. It reuses the gates' own judges, not copies. `--self-test` runs in CI: the 54 worked records pass and the 11 must-reject cases bound to these rules are each refused for the rule they name. CONFORMANCE.md §8 says how to run it and what 1.0.0 covers; §6's wire-level checklist is 1.x. First external run: the homelab estate, 1,925 records, all rules passing.
