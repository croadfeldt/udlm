**Log shippers and log stores filter by criterion** (amends ADR-083). A filter over log lines is a URF expression alone (`format: udlm-filter-expr`, URF-013): §9.2's comparators and connectives with no path, because a log line is not a record, and no virtual field, because it is not in the estate graph. Its fields are the OpenTelemetry Logs Data Model's (`severity_number`, `body`, `resource.*`, `attributes.*`; syslog fields under `attributes.syslog.*`), defined once as `LogRecordCriterion`. `LogShipper` 0.9.0 ships what matches `filter.include` and not `filter.exclude`, replacing `min_severity`; `LogShipper.Syslog` 0.2.0 drops `facilities`, now a criterion. `LogStore` 0.2.0 keeps `retention_days` as the default and adds ordered `rules` (first match wins) that set retention, readers, or both. Open value lists (sources, intake protocol and transport, syslog transport) are marked extensible. Maintainer ruling 2026-10-14.
