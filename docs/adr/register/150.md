**A start-here course, and the three fixes a newcomer asked for.** A fresh agent measured how long UDLM takes to start using: three minutes for an intent record, eight for a Provider Class, one for a layer. The only failure was a stale pin manifest, and the reading list sent a record author to spec-contributor documents. `docs/start-here/` now walks the model in short steps, each under 400 words and each ending with a command that proves it worked; steps 0 to 4 are written, 5 to 10 follow. Four fixes ship with it. The co-engineering front door names which example file to copy for a record, a class and a layer. `scripts/regen.sh` regenerates every derived file after a class change. `docs/authoring/layer.md` is the layer procedure the authoring table lacked. `scripts/signoff.sh --only` runs a named subset of gates while you work. Maintainer ask 2026-11-03.
