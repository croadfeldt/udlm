A UPS is a **base class of its own** (`UPS`, single-segment, instantiable) — passes the base test of row 069 / CLS-002: NUT's variable namespace and Redfish PowerEquipment abstract over every UPS topology (a), every base element is honorable by each (b), an order at `UPS` is fillable by any (c); `Facility` and a `Power` base both fail (a) — folders, not deliverables. `Facility.PowerFeed` 0.6.0 gains `supplied_by → UPS`; `PowerFeed` out of `Facility` is the recorded follow-up | Accepted — requires engineering ratification
