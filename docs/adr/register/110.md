**Network fields earn their place** (row 108 applied to the network group, #664). `zone` and `tier` sat on all twelve network Bases because the dissolved Network family had declared them and ADR-082 re-declared them per Base. Placement selects a *network* by them, so VLAN, Subnet and VirtualNetwork keep both; the other nine (IPAddress, IPAddressPool, DHCPScope, DNSZone, AddressService, ConnectionProfile, NetworkSwitch, NetworkGateway) drop them and reach their network's value through the edge they already declare. `ip_family` leaves Subnet, IPAddressPool and DHCPScope: each is derivable from a required prefix, as Subnet's own description said. IPAddress keeps it (for a lease, the family is the request) and NetworkGateway keeps `ip_family` (families routed is a declaration). VLAN `name` goes: it restated the handle's last segment. Ten classes take a MINOR bump; the shared-VLAN worked records are re-issued. Maintainer ruling 2026-10-23.
