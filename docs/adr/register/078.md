**Observed edges ride the discovered record.** A `discovered_record` MAY carry `dependencies`, edges a sweep saw. `target_key` is the key the probe read, a `correlation_ids` scheme and value; a compound key uses a scheme naming it. `target_uuid` appears once the control plane resolves it; an unresolved edge is written and reported, never refused. It is written only where the record's tenant may see the target (`GRD-001`); otherwise the edge stays key-only and resolution is a finding (ADR-060). A provider never supplies a UUID; it knows only those the control plane issued (`template-composition-model.md` §5.1; `PRV-012`, `DEP-018`, row 080). A discovered record refuses `strength`, `relation`, `bound_field` and `target_field`; the other kinds refuse `target_key`; drift compares both lists. An edge no probe can key-match is intent, entered by claiming. No provenance head; a discovered record references no record (row 076).
