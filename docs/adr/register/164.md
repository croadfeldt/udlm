**A machine can mount a directory inside a share, not only the share's root.** Machine 2.7.0 gives each `mounts` entry an optional `subpath`: the directory to mount, relative to the export's root, so a host can take `/Users/ethan` from an export of `/Users`. `share` names an export, and per-user home directories are directories inside one export, so before this a host that takes some users' homes from a file server and keeps others on a local disk could not say so. The name and meaning are Kubernetes `volumeMounts[].subPath`, adopted by reference. A `subpath` is relative: no leading `/` and no `..` segment, so a mount never reaches outside its export; the schema refuses both. Absent means the export root, so every existing record keeps its meaning. Maintainer ruling 2026-11-08.
