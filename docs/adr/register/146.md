**The CNCF Sandbox eligibility files exist.** The maintainer wants UDLM to live at the CNCF eventually (ruling 2026-11-03). The Sandbox application is eligibility, not maturity: Apache-2.0 (already), a MAINTAINERS file, a security policy, a code of conduct, a roadmap, a contributing guide (already), an adopters list, and a description of the spec's change process and conformance testing. The repository now carries all of them: `MAINTAINERS.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md` (the CNCF's), `ROADMAP.md` (pointing at the lockdown plan), `ADOPTERS.md`. Nothing is submitted; applying is the maintainers' call. Incubation would add three verified adopters, governance and a maintainer lifecycle, an OpenSSF badge and a security self-assessment.
