The working record and its provenance chains — receipt = states + leaf pin + `integrity` chain, nothing else (the record-content test: act-now in the record, explain-past in the ledger; claims discipline: record = state claims, ledger alone = history claims); provenance = typed chains (request / discovery-run / resource / RFC 9162 audit log) with the **admission rule** (no write without a citable pathway anchor — injection is source-blind) and **OpenLineage** seals (`pathway_ref` makes a request verifiable through to end state; disposition in adopted-standards §7). Artifact-family/projection/portability rulings live in the ADR-038 addendum | Proposed
