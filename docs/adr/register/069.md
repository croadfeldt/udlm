**A Base Class is a deliverable that any member can realize.** This supersedes row 068's test clause ("things one consumer intent can move between"): nothing moves; the portability events are placement, rebuild and substitution. Three conditions. An existing, widely used API already abstracts over the members (Nova/Ironic, Cluster API `Machine`, Kubernetes conformance, OCI, CSI). Every Base element is honorable beneath it (`LSK-001`). An offering declared at any tier accepts orders at every tier above. A category that fails the first is a folder: `instantiable: false`, never renamed. The Type tier is spent on form or dialect, whichever carries the structure. A class is named for its deliverable; a standard may appear, a product may not. One `short_name` per class, resolved on input, never stored (Kubernetes `shortNames`).
