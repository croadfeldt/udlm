**A refused request still carries a dispatch receipt.** When placement refuses before any provider is selected, the requested record's `dispatch` names the placement authority as `provider` with an empty `admitted` list: nothing crossed, and the record says so. One rule, no exceptions — a missing receipt never has to be read as "not dispatched" (`DSP-004`). Maintainer ruling 2026-10-06.
