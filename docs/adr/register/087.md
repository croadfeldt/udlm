**The Software folder dissolves; `Software.Service` is the `Workload` Base** (ADR-082 applied). A Workload is a running set of constituents with replicas and endpoints, the thing OAM, TOSCA and Kubernetes workloads abstract over, so Kubernetes, podman and systemd providers all fill it. It is named for the thing a provider yields, not the act it renders (Service = act, Resource = thing, 2026-06-27). It files under `services`; `service_kind` stays an element. No Resource folder Base remains; the Access family's `Access` and `Identity` folders wait on that family's group level. Same uuid; the map is in `registry/renames.yaml`. Maintainer ruling 2026-09-29.
