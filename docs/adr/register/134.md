**Values in the record schemas are snake_case too.** Row 103 set the rule for classes; this applies it to the record schemas. Two lists are renamed: the decision-record ladder (`proposed`, `under_review`, `canonical`, `observed`, `deprecated`) and a process's `execution_state` (`requested` to `cancelled`). Values that are not words UDLM made up keep their spelling and say why: `x-standard` for a value copied from a standard, `x-value-form: name` for names like `Resource` or `Intent`, `x-value-form: notation` for `0..n`. The audit ledger's uppercase action list is left alone because the ledger is experimental. Gate: `tests/check_schema_enum_casing.py`. Closes #641, #678.
