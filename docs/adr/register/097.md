**One quantity.** Every size in the model (memory, capacity, storage, layout entries) is `common-elements.schema.json#/$defs/quantity`. That is a number with an optional SI or binary unit and an optional trailing B, a superset of the nine patterns classes had declared one by one. Every CPU request is `#/$defs/cpu_quantity`: a number of cores or a Kubernetes quantity string, so Container and Database now accept the same values. Every change is a widening; no record valid before becomes invalid. Twelve classes take a MINOR bump. An offer may still narrow a quantity (AcmeThreeTier). Closes #638, #253. Maintainer ruling 2026-10-14.
