**Every rule the conformance suite applies has a case it must refuse** (WP7d; #434, #442; lockdown ruling 2). Nine new must-reject cases, 024–032, cover the nine suite rules that had none: the two integrity rules, the three transition rules, the two dispatch rules, and the payload checks on fields and outputs. Each case is a worked record with one thing broken, refused for exactly the rule it names. `tests/conformance.py --self-test` fails if any of its 14 rules has no case, so coverage cannot quietly shrink; `tests/check_must_reject.py` runs these cases too (33 of 33). For 1.0, "every checked rule" means every rule the suite applies. Cases for the other gates' rules arrive with their single-record entry points, in 1.x. A red CI is not a to-do list: no case exists for a rule nothing enforces.
