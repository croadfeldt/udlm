A composition is a **record** until someone offers it — an unoffered composition is a `composition` record carrying the same shape a class carries, so promotion to an offered Template is a status change and never a translation. Two semantic checkers cannot disagree about a shape neither one rewrites | Accepted (upstream) — requires engineering ratification
