**Every part of the spec says how stable it is** (lockdown WP0, ruling 4). `registry/stability.yaml` lists all 158 parts (71 classes, 27 record schemas, 60 spec documents) as stable, experimental or reference. Stable carries the 1.0 promise. Experimental may change in a minor and is not in the 1.0 claim. Reference states no rule. The first sort uses one rule per pattern. A class is stable if a use case exercises it and it is not under an open rename. The ledger schemas, the provider contract, the draft wire contracts and the documents behind open rulings are experimental. Result: 88 stable, 63 experimental, 7 reference. Eleven blockers in the lockdown plan stop blocking because their part is experimental. The maintainer rules on the list in the PR; a part changes stability only by a register row.
