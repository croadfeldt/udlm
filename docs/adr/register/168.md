**A machine can mount a directory inside a share, or a local volume in place of one.** Machine 2.8.0 gives each `mounts` entry an optional `subpath`, the directory to mount relative to the export's root, so a host can take `/Users/alice` from an export of `/Users`. It is Kubernetes `volumeMounts[].subPath`. A subpath has no leading `/` and no `..` segment, so a mount never leaves its export. An entry can instead name a Volume on the machine (`volume_ref`), so one home can stay on a local disk. An entry is exactly one kind. A volume entry is a `depends_on` edge, `mounts_volume`, so it can order; the requester sets its strength. A share entry stays a `mounts` reference. Whether a volume may be prepared before mounting, and how its data is protected, is policy (Vlad's review, 2026-11-23). Every existing record keeps its meaning. Maintainer rulings 2026-11-08 and 2026-11-09.
