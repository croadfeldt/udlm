**A software bill of materials is its own record, captured from a store and checked against it.** `SoftwareBillOfMaterials` 0.1.0 is a Knowledge class for one document about one subject: an image, a machine, a cluster, a device, or anything that carries software. The document stays in an SBOM store, its system of record. The record points at it by URL and digest and captures its package list as `contains` edges, so an advisory reaches every subject by a graph walk. A captured list is refreshed on a declared rhythm and validated by comparing digests. SPDX and CycloneDX are adopted for the document, the in-toto Statement for its signed form. SoftwareImage 0.4.0 gives up its direct edge to SoftwarePackage. Which things run an image is derived by matching digests. SoftwarePackage 0.5.0 covers operating systems and firmware with the CycloneDX component type and a CPE name. This settles #197. Maintainer rulings 2026-11-13.
