**A software bill of materials is its own record, and the thing it describes lists nothing.** `SoftwareBillOfMaterials` 0.1.0 is a Knowledge class for one document about one subject: an image, a machine, a cluster, a switch, a gateway or a management controller. It points at the document by URL and digest and carries one `contains` edge per package. SPDX and CycloneDX are adopted for the document and the relation names, the in-toto Statement for its signed form. SoftwareImage 0.4.0 gives up its direct edge to SoftwarePackage, so a rescan never rewrites the subject. Container 1.4.0 and Machine 2.7.0 declare `runs_image`. SoftwarePackage 0.5.0 covers operating systems and firmware with the CycloneDX component type and a CPE name. Schemes `oci_digest`, `purl` and `vulnerability_id` let a scanner name targets by natural key. This replaces the note that these records were a proof of concept (#197).
