**A reference lint that can fail** (WP7, #383). G3 checked only a `*_ref` declared `type: string`, so the object-form reference that row 101 removed passed silently, and any `$ref` at all counted as a reference shape. Now every `*_ref`, whatever its type, must be a URF reference. That means `format: udlm-ref-url` (or the filter and URI forms), a `$ref` that lands on a reference definition (`Reference`, `data_reference`, the network zone and tier references), or a `oneOf`/`anyOf` whose every branch is one. A self-test plants the object form, a `$ref` to a quantity and a bare string inside array items, and fails if G3 misses any. The registry has none. The issue's second hole, the stranded array-items arm, was closed by row 101.
