**`armv6l` is an instruction-set architecture** (a homelab Raspberry Pi Zero W). The shared `isa` codelist (common-elements, PVD-001) gains `armv6l`, the `uname -m` spelling a 32-bit ARMv6 host reports; discovery had refused that host's record because the value was not in the list. OCI's `arm` already covers it (the variant is separate).
