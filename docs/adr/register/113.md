**Host and device fields earn their place** (row 108 applied to BMC, NetworkInterface, BareMetalHost and NetworkSwitch, #664). BMC 0.9.0 drops its `power_state` output, the host's observed run state is the fact (row 111), and its free-text `vendor` becomes the shared `identity` block; it now publishes no outputs of its own and says so. NetworkInterface 0.17.0 drops `vlan_id`, an observed tag that resolution promoted into `vlan_memberships`: a discovered edge's `target_key` (RHY-007) is that mechanism. BareMetalHost 0.17.0 and NetworkSwitch 0.11.0 drop `allocation_state`: available is Discovered with no Intent, allocated is having one, retired is Decommissioned, all read from the state records; common-elements §6 now says so and row 099's rename is superseded. BareMetalHost also drops the `provisioning_state` output, the four states in Metal3's words, and replaces `boot_mac_address` with `boot_interface_ref`, a reference to the NetworkInterface whose `identity.mac_address` the Metal3 provider reads. Maintainer rulings 2026-10-25. Row 114 (storage fields) is in flight.
