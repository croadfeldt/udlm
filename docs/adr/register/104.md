**`state` keeps its name; the document it is on says which meaning.** On a state record, `state` is the lifecycle position (Intent, Requested, Realized, Discovered). On a definition (a class element, a decision record, a composition record) it is how far the definition has got through review. `record_type`, or the class element around it, always tells a reader which. Renaming the review meaning to `curation_state` would touch 337 elements in 69 classes for no gain the document type does not already give, so naming-conventions §4 states the rule instead. Maintainer ruling 2026-10-22. Closes #640 (the allocation half was row 099).
