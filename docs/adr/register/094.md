**A spec example says what it is** (`DOC-003`). Every YAML example under `docs/spec/` declares `# schema: <file>` — and then uses only fields that schema allows — or `# illustrative`. A field audit found 57–66% of example keys in two contracts were a property of no schema (#632, #634, #635); this gate stops that from regrowing. The 318 unmarked examples present when it landed are baselined by content hash; editing one, or adding one, requires the declaration. Maintainer ruling 2026-10-13.
