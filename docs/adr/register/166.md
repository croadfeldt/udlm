**A machine can mount a directory inside a share, or a local volume in place of one.** Machine 2.7.0 gives each `mounts` entry an optional `subpath`, the directory to mount relative to the export's root, so a host can take `/Users/ethan` from an export of `/Users`. The name and meaning are Kubernetes `volumeMounts[].subPath`. A subpath has no leading `/` and no `..` segment, so a mount never leaves its export. An entry can instead name a Volume on the machine (`volume_ref`), so a host keeps one home on a local disk while the rest come from the file server. An entry is exactly one kind, and the schema refuses one that names both. A volume entry is a `mounts_volume` edge, as a share entry is a `mounts` edge. Every existing record keeps its meaning. Maintainer rulings 2026-11-08 and 2026-11-09.
