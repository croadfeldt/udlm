**A class is defined once and filed under usage groups like hard links.** Tier comes from `class` and `parent`, never from the name (`CLS-001`). A Base declares `filed_under`: a set of terms from `registry/taxonomies/usage-group.yaml`; a filing is organization, bumps nothing, and is never on a record (`CLS-010`, `CLS-011`). `.` is a tier, `/` a locator; a Base name stands alone (`CLS-012`). One hosting directory, other filings generated (`CLS-013`). The eight folder Bases dissolve into group terms; members become Bases by the Base test or are re-homed, renamed per family in follow-up PRs. `filed_under` is a URF virtual field (`URF-010`, `URF-011`). Maintainer ruling 2026-09-29.
