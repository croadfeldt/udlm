**Enum values are snake_case.** Naming-conventions §4 said enum values were lowercase and hyphenated, but most of the registry already used snake_case, the same casing as keys. Maintainer ruling 2026-10-22: every word UDLM mints, key or value, is snake_case. A value copied verbatim from an adopted standard keeps its casing, and its element says so with `x-standard: "<standard>:<where>"` naming a standard the class adopts: Kubernetes taint effects and StorageClass policies, Metal3's `live-iso`, NMstate bond modes, OTLP protocols, Swordfish RAID types. Thirteen classes rename their own values (MINOR), for example `at-most-once` to `at_most_once` and `fleet-manager` to `fleet_manager`; NetworkInterface now adopts NMstate for its bond modes. The test-evidence worked records are re-issued with the new values, superseding the old ones and resealed. Gate G9 refuses any other non-snake enum value in a class. Record-schema vocabularies follow separately (#657). Part of #641.
