# vocabulary-intake — strings meet SharedDataElements without toil

Six cases for the intake ladder (docs/design/vocabulary-intake-ladder.md): a plain string
matches an in-scope element and binds free (001); mints at current scope as proposed when
unmatched and the profile permits (002); earns promotion with dedup at promotion time (003).
The negatives hold the line: near matches are surfaced, never silently bound, in every
profile (004); match-only estates refuse unknown strings naming candidates and the proposal
path (005); canonical-only estates extend vocabulary through their own change control, with
interim refusals citing pending proposals (006). Strictness gates minting, never matching;
the ladder's justification is toil accounting per the north star.
